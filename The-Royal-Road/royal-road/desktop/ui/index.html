Setup

1Cloud relay

Dreams wait here, encrypted, between your phone and this computer. Create a free Supabase project, run cloud/setup.sql in its SQL Editor, then paste the two values from Project Settings › API.

2Phone

Install the Royal Road app on your Android phone, then scan the code below from its Pair screen. Only fill in the address if you put the web version online instead.

The pairing code appears once the cloud relay is filled in.

3AI

The AI names each dream's threads and answers in Chat. Without one, the built-in analyzer still files and links every dream.

4Transcription

Turns what you say into the dream's words when you press Transcribe. Groq is the cheapest and fastest; OpenAI can reuse the key above.

5Pictures

Creates a picture for a dream when you ask. Uploading your own pictures works without this.
